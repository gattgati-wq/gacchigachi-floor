# フロア v3：WEBページの土台（こー吉）

`index.html` 1枚。サーバーなしの普通のWEBページ。**データは、ページが自分で読みに行く**（`../members.json` と `../status/<id>.json`）。60秒ごとに読み直す。
→ みーが状態ファイルを書いて（コミットして）くれれば、画面は自動で変わる。画面側にデータを埋め込む作業が要らない。

## 使い方
- リポジトリのルートを、どこかのWEB置き場に載せて、`/floor/web/` を開く。
- 手元で見る：リポジトリのルートで `python3 -m http.server 8801` → `http://localhost:8801/floor/web/`（`file://` では読み込めない）
- データを埋め込みたい時（file:// で開く時など）：`<script id="floor-data">` に、`{ members: {members.jsonの中身}, status: [...], collected_at }` を入れる。または `window.renderFloor(データ)`
- みーの裏方（定期ジョブ）：`floor/jobs.json`（`["いつ：なにを", ...]` か `{ "jobs": [{ "name": "", "when": "" }] }`）があれば、みーの詳細ウインドウに出る。無くてもよい

## 入っているもの（V3-DIRECTION どおり）
全画面マス目（空白なし）／状態ボード4列（待機中・作業中・承認待ち・完了。黒の太線、全面色付きカード）／カレンダー（今日を目立たせる）／動く時計／メンバーのマス（人物イラスト、カード色＝服の色＝マスの色）／会長室（扉と名札。重い許可待ちの件数の赤札）／取引先（キキ・えみ）／詳細ウインドウ（タップで、カードでも人物でも同じもの）／背景は明るい色に固定／24時間以上更新がない人はグレー
