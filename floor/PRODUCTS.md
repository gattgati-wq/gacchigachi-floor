# 完成品置き場（floor/products.json）

フロア画面の右の縦長ボード「完成品置き場」に出す、**完成した成果物の名前の一覧**。

## 何を置くか（すぎちゃん決定 2026-11-23）
- **最終形態になった作成物**。Claudeのアーカイブにいる子たち（終わったセッション）の分も含める。
- 今も動いてる子なら、**「その時点で完成してるもの」＝現在の完成形**（例：「予約システム（いま完成している分）」）。
- 次にやる予定のアンプ改造も、**できたら、ここに置く**（できるまでは、置かん）。
- 置くのは**名前だけ**。日付もリンクも無し（決定済み）。

## 誰が書くか
- **みーが持つ**（名前の一覧を、みーが書いて、更新する）。ほかの子は書かん。

## 書き方
```json
{ "products": ["名前1", "名前2"] }
```
- 上から順に、ボードに縦に並ぶ（多い時は、ボードの中をスクロール）。
- 名前は短めに（長いと折り返す）。完成形が変わった時は、名前を書き換えるか、足す。

## 公開の注意
- このリポジトリと画面は**公開**。**お客さんの情報（名前・予約内容・連絡先）、人に見せたくない物の名前は、書かん**。
