# フロア新デザイン（試作 v4）

キキの素材とすぎちゃんのレイアウト例をもとにした試作。**v3（floor/v3/）はそのまま残してある**（置き換えるのは、すぎちゃんが見て決めてから）。

## 配置（すぎちゃんの修正案で組み直した）
- 左の列：状態ボードと、**縦に目一杯の拡声器**。日時プレートは左列から出して、**写真の上の真ん中**へ。
- 右：**完成品置き場を、高さ目一杯の縦長**に。
- 真ん中：店の写真（床の広い所に10人）。
- 枠は、キキの枠を、角と辺を固定して縦長に組み直したもの（`ui/mega-tall.webp` `ui/products-v.webp`）。

## ボード類も、ドラッグで動かせて、大小も変えられる（すぎちゃんの追加案）
- 対象：状態ボード・日時プレート・拡声器・完成品置き場。キキとえみの丸アイコンは、動かすだけ（大小は変えん）。
- **動かす**：ボードの枠や、何も無い所をつかんで、ドラッグ。マグネットや連絡文の上からでも動かせる（動かさんクリックは、今まで通り詳細が開く）。入力欄・コピーボタンは、そのまま使える。
- **大小を変える**：ボードの右下の「◢」（さわると見える）をドラッグ。**縦横の比は固定**して、大小だけ変わる（枠の絵が歪まんように）。0.4倍〜2.2倍。舞台の外には出ん。
- 位置と大きさは、**この端末のブラウザだけ**に覚える（共有はされん）。左下の「配置を戻す」で、キャラも、ボードも、もとに戻る。
- さわったボードが、いちばん手前に出る（キャラよりは奥）。
- 注意：小さくしすぎると、中の文字は読めんくなる。

## 更新（リアルタイムではない）
- 画面は、**開いた時と、毎分**、ファイル（members／状態／拡声器／完成品）を読み直す。リアルタイム（変わった瞬間に反映）ではない。
- **「更新」ボタン**（写真の上の右上）で、今すぐ読み直せる。ボタンの下に「データ hh:mm:ss 時点」が出る。ライブで読めんかった時は、赤っぽい字で「（埋め込み＝古い可能性）」と出る。
- 読む時は、毎回URLに時刻を付けて、古い写しを使わんようにしている。
- ただし、反映されるのは**GitHubのmainに入ったファイルまで**。状態ファイルを書いた社員が push して、公開側（GitHub Pages）に出るまで、1〜数分かかることがある。ボタンを押しても、それより新しいものは出ない。

## みー：空を飛ぶ来訪者（すぎちゃん決定）
みーは社員ではなく「すぎちゃんの秘書で、たまに見に来る」立場。**デスクには座らん**（`SEAT` から外した）。
- 流れ：飛んでくる → まなの隣に降りておしゃべり（まなは立ち止まって、正面を向く。吹き出しで掛け合い） → ボードの前へ飛んで内容を見る → 飛んで帰る。1回に約20秒。次の来訪まで50〜100秒おき（最初は開いて8秒後）。
- 状態ボードの「みー」（ピンク）は、そのまま残す。
- 動きは、時間で動かしているだけ（状態ファイルとは連動しない）。「動きを減らす」設定では、来訪しない。ドラッグはできない。クリックで詳細は開く。
- **みー用の絵は、キキの新規待ち**。くわしい仕様は `floor/v4/MII-ASSETS.md`（飛んでる姿は、スーパーマンみたいな格好・ポーズ。**飛ぶ絵は右向き・左向きの両方**）。**2026-11-22 に5枚が届いて組み込み済み**（飛んでる右・左、おしゃべり、ボードを見る後ろ姿、飛んで帰る右）。**飛んで帰る・左向きだけ未着**で、届くまでは右向きを反転して使う。届いたら `img/mii-away-l.webp`（512px・透過）を置いて、index.html の `VISIT_ART.away.l` を `true` にするだけ。
- 設定：`VISIT_CFG`（来訪の間隔）、`BOARD_SPOT`（ボードの前の位置）、`CHAT`（おしゃべりの台詞）。
- 名札は members.json の `title`（いまは「社長代理」）。世間向けの役割名を「秘書」にするなら、みーが members.json を直す。

## 動きは各自バラバラ（すぎちゃんの修正）
- 全員が同じ動きで揃わんように、キャラごとに「くせ」を付けた：速さ・始まりの位置・向き・大きさを、idから決める（再描画しても変わらん）。呼吸も、あくびも、完了の跳ねも、各自ずれる。
- **作業中は、パソコンをカタカタ打つ動き**：斜めに、小刻みに、不規則に動く（向きは、右上がりと左上がりが、キャラごとに違う）。「動きを減らす」設定では止まる。

## キャラの反応・ドラッグ（すぎちゃんの追加案）
- **クリック**：キャラが跳ねて、ひとこと吹き出し（寝てる子は「…ん？ 起きた〜」で、仕事の絵に切り替わって起きる。2.6秒後に元に戻る）。そのあと、詳細ウインドウが開く。
- **ドラッグ＆ドロップ**：キャラを好きな場所へ動かせる（少し動かしたらドラッグとみなす。つかんでる間は浮く。画面の外には出ない。スマホ・タブレットのタッチでも動く）。
- 動かした位置は、**この端末のブラウザだけ**に覚える（localStorage）。ほかの人・ほかの端末には共有されない。左下の「配置を戻す」で、もとの席に戻る。
- まなも動かせる（つかんでる間は手を振って待つ。離したら、そこから歩きを続ける。まなの位置は、覚えない）。
- 「動きを減らす」設定では、跳ねは止まるが、起きる（絵の切り替え）とひとことは出る。

## 作りの方針
- 画面は **1600×1020（約1.57:1）の1枚の舞台**。窓の大きさに合わせて丸ごと拡縮する。位置は全部、舞台の座標で決める → どの大きさでも10人が1画面に収まる（1280×800／1440×900／1512×982／1728×1117／900×600 で全員が見えるのを確認済み）。
- データは v3 と同じ：`floor/members.json` と `floor/status/*.json`、拡声器 `floor/megaphone/`。開くたびに読む。埋め込みの更新は `python3 floor/v4/embed.py`。
- 完成品置き場の名前は `floor/products.json`（`{"products": ["名前", ...]}`）。置くのは名前だけ。**書くのは みー**。

## 絵の割り当て（すぎちゃん決定）
| 状態 | 絵 |
|---|---|
| 待機（普通）・承認待ち・完了 | 仕事の絵（`<id>-normal`）。承認待ちは止まって「許可まち」の吹き出し、完了は緑のチェック＋跳ねる |
| 作業中（依頼作業中） | 焦りの絵（`<id>-busy`）。小刻みに揺れる |
| 待機24時間〜（ヒマ） | あくびの絵（`<id>-yawn`） |
| 待機72時間〜（長らくヒマ）・止まってる（作業中や待ちで6時間以上更新なし） | 寝てる絵（`<id>-sleep`）。止まってる時は赤い「⚠」タグ |
- 時間のしきい値は index.html の上の設定（`YAWN_MS` `SLEEP_MS` `STALL_L1`）。72時間はまなの仮の数字。
- **まなは寝ない**（`NO_SLEEP`）。まなはフロアの床を往復して歩く（③④の2コマ。右向きは反転。端で手を振る）。
- 親方は仕事・焦りが2コマ（`normal2` `busy2`）。切り替えて動かす。
- 「動きを減らす」設定では、揺れ・歩き・コマ切り替えを止める。日時の秒更新は止めない（情報だから）。

## 枠・マグネット（キキの画像を、こっちで切り抜いて使っている）
キキの納品は白（または黒）背景のJPEGやったので、**透過PNGの再納品を待たず、背景を切り抜いて使った**（すぎちゃんの提案の方向）。`ui/` の中：
- `board.webp`：状態ボード。見出し（待機中／作業中／承認待ち／完了）は画像に入っている。
- `plate.webp`：日時プレート。**焼き込みの日付と時刻の数字は、まなが消して**、日付・時刻はコードで載せる。
- `mega.webp`：拡声器ボード（縦長）。
- `products.webp`：完成品置き場。キキの縦長の枠を、**角と辺を固定して、まなが横長に組み直した**（蓮の飾りは伸ばさず、真ん中に置いた）。
- `mag-*.webp`：名前マグネット12個（キキの10色＋みー作のタン・藍色。タン・藍色は左右の丸い端を残して中を詰め、比率を約2.4:1に）。
- 切り抜きは、周囲の白（黒）をつなげて透明にする方式。縁が少し硬い・少し削れている所があるかもしれない。本当の透過PNGが届いたら、同じファイル名で差し替えれば、コードは変えなくてよい。

## 拡声器・名札
- 拡声器：連絡を書く欄あり（v3と同じ）。**共有保存はできんので、コピーして、みーが `floor/megaphone/current.json` に置く**。書いてる途中の文は、毎分の再読み込みで消えん。
- 名札：各キャラの足元に、役割名（members.json の title）。

## まだ仮のもの・未移植
- 「会いに行く」：詳細ウインドウに、`members.json` の `link`（**https のみ**）があれば出る。キキ・えみは `partners: {"kiki": "https://…", "emi": "https://…"}`。**リポジトリは公開なので、ログインが要るページや秘密のURLは書かない**。

## 素材
`img/` は 512px の透過WebP（約3MB）。もとは1125px前後。足元の影・白い縁取り・効果（汗・Zzz）は絵に焼き込まれたまま。
背景 `img/bg.webp` は、店の写真（すぎちゃん提供）を切り出したもの。
