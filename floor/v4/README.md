# フロア新デザイン（試作 v4）

キキの素材とすぎちゃんのレイアウト例をもとにした試作。**v3（floor/v3/）はそのまま残してある**（置き換えるのは、すぎちゃんが見て決めてから）。

## 作りの方針
- 画面は **1600×1020（約1.57:1）の1枚の舞台**。窓の大きさに合わせて丸ごと拡縮する。位置は全部、舞台の座標で決める → どの大きさでも10人が1画面に収まる（1280×800／1440×900／1512×982／1728×1117／900×600 で全員が見えるのを確認済み）。
- データは v3 と同じ：`floor/members.json` と `floor/status/*.json`、拡声器 `floor/megaphone/`。開くたびに読む。埋め込みの更新は `python3 floor/v4/embed.py`。
- 完成品置き場の名前は `floor/products.json`（`{"products": ["名前", ...]}`）。置くのは名前だけ。**書くのは みー**。

## 絵の割り当て（すぎちゃん決定）
| 状態 | 絵 |
|---|---|
| 待機（普通）・承認待ち・完了 | 仕事の絵（`<id>-normal`）。承認待ちは止まって「許可まち」の吹き出し、完了は緑のチェック＋跳ねる |
| 作業中（依頼作業中） | 焦りの絵（`<id>-busy`）。小刻みに揺れる |
| 待機24時間〜（ヒマ） | あくびの絵（`<id>-yawn`） |
| 待機72時間〜（長らくヒマ）・止まってる（作業中や待ちで6時間以上更新なし） | 寝てる絵（`<id>-sleep`）。止まってる時は赤い「⚠」タグ |
- 時間のしきい値は index.html の上の設定（`YAWN_MS` `SLEEP_MS` `STALL_L1`）。72時間はまなの仮の数字。
- **まなは寝ない**（`NO_SLEEP`）。まなはフロアの床を往復して歩く（③④の2コマ。右向きは反転。端で手を振る）。
- 親方は仕事・焦りが2コマ（`normal2` `busy2`）。切り替えて動かす。
- 「動きを減らす」設定では、揺れ・歩き・コマ切り替えを止める。日時の秒更新は止めない（情報だから）。

## 枠・マグネット（キキの画像を、こっちで切り抜いて使っている）
キキの納品は白（または黒）背景のJPEGやったので、**透過PNGの再納品を待たず、背景を切り抜いて使った**（すぎちゃんの提案の方向）。`ui/` の中：
- `board.webp`：状態ボード。見出し（待機中／作業中／承認待ち／完了）は画像に入っている。
- `plate.webp`：日時プレート。**焼き込みの日付と時刻の数字は、まなが消して**、日付・時刻はコードで載せる。
- `mega.webp`：拡声器ボード（縦長）。
- `products.webp`：完成品置き場。キキの縦長の枠を、**角と辺を固定して、まなが横長に組み直した**（蓮の飾りは伸ばさず、真ん中に置いた）。
- `mag-*.webp`：名前マグネット12個（キキの10色＋みー作のタン・藍色。タン・藍色は左右の丸い端を残して中を詰め、比率を約2.4:1に）。
- 切り抜きは、周囲の白（黒）をつなげて透明にする方式。縁が少し硬い・少し削れている所があるかもしれない。本当の透過PNGが届いたら、同じファイル名で差し替えれば、コードは変えなくてよい。

## まだ仮のもの・未移植
- 拡声器：読むだけ。連絡を書く欄は未移植。
- 名札（役割名）：レイアウト例に位置が無いので、まだ出していない。
- 「会いに行く」：詳細ウインドウに、`members.json` の `link`（**https のみ**）があれば出る。キキ・えみは `partners: {"kiki": "https://…", "emi": "https://…"}`。**リポジトリは公開なので、ログインが要るページや秘密のURLは書かない**。

## 素材
`img/` は 512px の透過WebP（約3MB）。もとは1125px前後。足元の影・白い縁取り・効果（汗・Zzz）は絵に焼き込まれたまま。
背景 `img/bg.webp` は、店の写真（すぎちゃん提供）を切り出したもの。
