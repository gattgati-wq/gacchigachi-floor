# フロア画面（段2・ミニ版）

`index.html` 1枚で動く表示専用の画面。データは中に埋め込む。

## みーの使い方
1. `floor/members.json` と `floor/status/*.json` を読む
2. 下の形にまとめて、`index.html` の `<script id="floor-data" type="application/json">` の中身と入れ替える
3. Museのスペースに設置する

すでに開いている画面を差し替える場合は、`window.renderFloor(データ)` を呼んでもよい。

```json
{
  "collected_at": "集めた時刻（+09:00付き）",
  "members": { members.json の中身そのまま },
  "status": [ status/*.json の中身を並べたもの ]
}
```

## 表示のきまり
- 吹き出し：状態ファイルの `say`（30字まで）と `updated` の時刻だけ。画面側で文章は作らない
- 位置：作業中・他の社員待ち・完了＝自分の席／待機＝休憩スペース／軽い許可待ち＝社長代理席の前／重い許可待ち＝会長室の前（扉に件数の赤札）
- みー（社長代理席）は常に席にいる
- 24時間以上更新がない、または状態ファイルがない社員は、グレー＋居眠り＋「最終更新〇日前」
- 会長室はキャラなし。扉と名札だけ
- スマホは横向きで表示。縦のときは「横にしてね」だけを出す
