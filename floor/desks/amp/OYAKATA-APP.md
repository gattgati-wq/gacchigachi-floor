# 親方へ：店内ディスプレイ アプリ版 試作の手順（M1・約15分・試作のみ。本番ではない）

作成：アンプ（まな経由）／**(b)＝M1で親方が実行**（すぎちゃんの判断・2026-11-26）／**M1専用・M1の最新OSが基準**（12インチは使わない）
※ここに出てくる `proto.zip` は、**すぎちゃん（またはみー）が親方に渡す**（リポジトリには置かない）。**値・鍵は、どこにも書いてない**。
※**確認だけ**（設定の変更は、変える前に、すぎちゃんに確認）。**WiiMへは何も送らん（ダミー）**。

## 0 事前確認（コマンドは1行ずつ。出るのは版の数字だけ）
- `uname -m` ………… `arm64` と出れば、M1（Apple Silicon）
- `sw_vers -productVersion` ………… OSの版（M1の最新OSか確認）
- `node -v` ………… 版が出れば Node.js あり。「command not found」ならなし
- `npm -v` ………… 同上
- `xcode-select -p` ………… パスが出れば、Xcodeの道具あり（※今回の試作＝Electronでは**不要**。後で案2（Swift）に乗り換える時だけ要る。無くてよい）
- **入ってない時**：Node.js が無ければ、**入れるかどうかと入れ方は、親方が決める**（アンプは決めない）。**入れない場合は、この試作は止める**（すぎちゃんへ）。

## 1 組み立て（3行）
`proto.zip` を、デスクトップなどに置いて解凍（`unzip proto.zip`）。できた `proto` フォルダに移動して：
1. `npm install --save-dev electron`
2. `npx @electron/packager . GattgatiDisplay --platform=darwin --arch=arm64 --out=out`
- （ネットから部品を取る：npm と Electron本体のダウンロード。数分かかる）
- できる物：`out/GattgatiDisplay-darwin-arm64/GattgatiDisplay.app`

## 2 成功の目安
- エラーなく終わって、上の `.app` ができる。
- `.app` を開くと、**全画面**で、アンプ画面（時計・カレンダー・ガネチ・メーター）が出る。

## 3 試作の確認ポイント
1. 全画面で開く。
2. **画面を暗くしない**（そのまま数分放置しても、ディスプレイが消えない）。
3. `Cmd+Q` で終了する。
4. **WiiMへは何も送らない（ダミー）**：アドレスはダミーにしてあり、通信は偽物に差し替えてある。確認方法＝ `proto/app/index.html` に**実際のアドレスの数字（`192.168` で始まる値）が無い**こと：`grep -c "192.168" proto/app/index.html` が **0** と出る。※右上の点が「**黄**」になるのは正常（偽物が成功を返すから）。**本物とつながったという意味ではない**。
5. 音量：最初は「音量 ？」と出る。数字を打って Enter で基準が決まる（これもWiiMには送らない）。←→で針の振れ幅が変わる。
6. プレーヤー：`M`＝プレイリスト（↑↓ Enter）／`Space`＝再生・停止／`N`＝次。ジャケット（仮の絵）がカレンダーの上に出る。
7. キー：`B`／`K`／`J`／`G`／`P` が反応する。
- ※文字（フォント）だけは、起動時に Google Fonts から取る（今のSafari版と同じ）。ネットが無いと、文字の見た目が変わる。
8. **署名なしの初回の警告**：M1で自分で組み立てた物は、警告が出ないことが多い（知らんけど）。出た時は、`.app` を右クリック→「開く」→もう一度「開く」。それでもダメなら、システム設定→プライバシーとセキュリティ→下の方の「このまま開く」。

## 4 後始末（試作を消す）
- `Cmd+Q` で終了してから、**親方が**ゴミ箱へ：解凍した `proto` フォルダ（`out` と `node_modules` も中に入ってる）。
- 試作が音量の記憶などを置く場所（名前は、次の2つのどちらか・知らんけど）：`~/Library/Application Support/` の中の「gattgati-display」または「GattgatiDisplay」。`ls ~/Library/Application\ Support | grep -i gatti` で見つかった物を、親方がゴミ箱へ。
- ログイン時の自動起動は、試作では**登録してない**（消すものなし）。
- **消す前に、すぎちゃんに一声**。
