# LINEデスクの仕事を、予約システムとみーへ移す：段取りの案

作成：まな／状態：**案**／このリポジトリは**公開**（お客さんの情報・鍵の値は書かん）
決定（すぎちゃん・2026-11-26）：「とりあえずLINEは予約システムとみーに移行する」。LINEの子の判断待ち（メニュー延長＝しない／太客タグ＝付けない）は、**全部閉じた**。
※「知らんけど」「要確認」は、まなが確かめてない所。こー吉・LINEの子・みーに確認する。

## 0. 前提
- **慎重枠**：予約システムは、本番稼働中で、本物のお客さんが使う。**移行の途中で、お客さんに影響を出さん**。
- **送信は、すぎちゃんの許可制のまま**（1通でも）。移行しても、**勝手に送る子は作らん**。
- 移行は**「寄せる」**：LINEの子の仕事を**棚卸し**して、**1つずつ受け皿を決める**。**一気に切り替えん**。

## 1. 仕事の棚卸しと、受け皿の案（LINEの説明書 `line.md` から。**LINEの子に確認してもらう**）
| LINEの子の仕事 | 受け皿の案 | 理由・注意 |
|---|---|---|
| チャット画面からの個別送信（全員へ順に） | **予約システムの「一斉送信」**（#202。名字＋さんの名前入りカード、1秒おきに1人ずつ） | もう出来てる。**スタートはお客さんに届く**＝すぎちゃんの合図まで、誰も押さん |
| 管理画面の絞り込み配信 | **予約システム**（一斉送信の対象の絞り込み）／絞れん分は**みー** | **絞り込みの条件を、システムが持てるか**＝要確認（こー吉） |
| 名簿とLINEの照合 | **予約システム** | 顧客のLINE紐付けは、**予約システムのDBが持ってる**（説明書）。システム側が自然。**名前なし・未来日付の人の扱い**も、移す |
| オーディエンスの管理（除外用「11/15」など） | **予約システム**（除外の設定）／当面は**みー** | **一斉送信の除外**（本人＋特定の1名）を、**システムが持つ形**にできるか＝要確認。**値は説明書に書かん** |
| 「太客」タグ付け | **やめる**（すぎちゃん：反応した人へは付けない）。**既存のタグ・除外条件は、そのまま残す** | **外すと除外条件が崩れる**（既存の注意） |
| リッチメニュー「テスト」 | **延長しない（終了）**。**削除・変更は、すぎちゃんの許可** | いま動いてる仕掛けの**止め方**を、LINEの子が書く |
| 店アカでの返信・変更の合図への対応 | **みー**（もう、そう） | こー吉＝検知と初動、みー＝その後の返信。**境目は、HANDOFFが正本** |
| 暗黙のルール（一覧は下が古い順、など） | **引継ぎ文**にして、**みーとこー吉へ** | 説明書に書けん分（除外の特定の1名）は、**みーが別ルートで持つ**（今まで通り） |

## 2. 段取り（案。1段ずつ。通ってから次）
1. **棚卸しの確認**：LINEの子に、**上の表が合ってるか**、**抜け**（表に無い仕事・手順・頻度・リスク）を、**1回だけ**出してもらう。**送信・配信・タグ付けは、しない**（質問に答えるだけ）。
2. **受け皿の決定**：表の各行を、**みー・こー吉・すぎちゃん**で確認（**こー吉は「システムでできる／できん」**を返す）。**送信が絡む所は、すぎちゃんの許可**。
3. **こー吉への依頼**（できる分）：**1項目ずつ**、**小さく**依頼（慎重枠のルールどおり：ブランチ・下書きPR・テスト・本番へは許可のうえ）。
4. **並走期間**：**LINEの子は待機のまま残す**（新しい受け皿が**動くのを確認するまで**）。**切り替えは、項目ごと**。
5. **切り替えの判定**：項目ごとに、**「新しい受け皿で、同じ結果が出た」**を、**すぎちゃんの本人アカウントで確認**（お客さんには送らん）。
6. **LINEデスクの終了**：全項目が移ったら、**LINEの子をアーカイブ**（削除せん）。**説明書 `line.md` は「移行済み」の表に更新**して残す（`CLAUDE.md` の1行は、すぎちゃんの判断で外す／残す）。
7. **フロアの反映**：名札「LINE」と席（`ganechikun`）を、どうするか（**消す／「移行済み」と表示／そのまま**）＝**すぎちゃんの判断**。

## 3. 危ない所
- **移行の途中で、除外の漏れ**（送ってはいけない相手に届く）：**除外の移し替えは、一番慎重に**。**移した後、本人アカウントで試す**。
- **「太客」タグを外して、除外条件が崩れる**。
- **一斉送信のスタート**：お客さんに届く。**合図まで、誰も押さん**。
- **LINEの子が持ってる、説明書に無い知識**：**アーカイブ前に、引継ぎ文を作る**（アーカイブは削除ではないので、**後から見られる**）。

## 4. すぎちゃんの判断が要る点
1. 受け皿の表（§1）で、**みーに寄せる分／システムに寄せる分**の線引き。
2. **各項目の切り替え**（送信が絡む所）。
3. 終わった後の**LINEの名札・席**（§2-7）。
