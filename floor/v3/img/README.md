# キャラ素材（ガネチ／ガチコ）置き場

画面は、ここにファイルが置かれた子から順に、自動で絵が切り替わる（無い子は今のイラストのまま）。

## 必要なファイル
`<メンバーID>.png` × 9人分。**全身・メンバー色の色違い・透明背景**のPNG。
ID：mii / koukichi / oyakata / sekkeikakari / hptantou / ganechigamen / chii / bucho / ganechikun

## 決まり
- 全ファイル同じ大きさの正方形（例 512×512）。背景は透明。
- 服（または体）の色はメンバー色（`floor/v3/index.html` の `COLORS`）。ボード・マスの色と揃える。
- 割り振り：ガチコ＝みー・ちぃ・フロア設計係・HP担当／ガネチ＝こー吉・親方・ガネチ画面・部長・ガネチくん
- 親方だけ特別仕様：炎仕様（赤系・怒り眉・炎の持ち物）。
- 持ち物は大きめ・単純な形（小さい画面で潰れんように）。
