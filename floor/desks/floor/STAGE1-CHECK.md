## チェック表（各項目：OK／直す／不明）
### A 置き場・権限
1. 見張りスクリプト・plist・ログ・「前回の位置」・STOP・ロックは、**全部リポジトリの外**（Mac側の専用フォルダ）。スクリプトは**手で入れた**（pullで中身が変わらん）。
2. **fetchだけ**。checkout・merge・pull・resetは**しない**（作業ツリーを動かさん）。読むのは `git show origin/main:<path>` や `git diff <前回>..origin/main -- <path>` の形。**fetch先（URL・ブランチ）は、スクリプトに固定**。リポジトリの文から取らん。
3. **鍵は置かん**。リポは公開やから、段1は**鍵なしのfetch**でできるはず（知らんけど、試して確認）。**鍵は段3より前に入れん**。
### B 判定
4. 「前回の位置」は**Mac側のファイル**（コミットsha）。**ログを書いた後に更新**する。位置ファイルが消えた時は、**全履歴を新規扱いにせず、止めて人が決める**。
5. 前回の位置が**今のmainの祖先でない**（force-push・履歴書き換え・ブランチ消失）→ **処理せず停止**（人が解除するまで戻らん）＋ログ。**位置を自動で直さん**。
6. **「追記だけ」判定**：対象ファイルの差分が**末尾の追加だけ**か。途中の変更・削除は「異常」としてログ（**中身は読んで動かん**）。
7. **見る場所を固定**：決めた受け箱のパスだけ。他のパスの変更は無視。
8. **本文をシェルに渡さん**：ログに書くのは、**sha・パス・追加行数・バイト数・時刻だけ**。**本文をコマンドの引数・evalに入れん**。ログにも写さん（公開に混ざる・指示の混入を防ぐ）。**変数は必ず引用符つき**。
### C 止め・ロック・ログ
9. **STOPファイルがあれば、何もせず終わる**。人が消すまで戻らん（**再起動後も**）。
10. **二重起動しない**（mkdir式のロックなど）。取り残しは、**勝手に奪わず**、ログに目立つ印＋通知。launchd再起動後に戻るか。
11. **時間上限**（fetchが固まる）：時間切れで終了。**ネット断は、失敗を数えて間隔を空ける（バックオフ）**、復帰後は通常に戻る。macOSに `timeout` は標準で無い（知らんけど）ので、**別の手段を親方に**。
12. **ログの置き場・大きさの上限**（ローテーション）。ディスクを食い潰さん。
### D 試験（**作り話のリポ**で。本物の情報なし）
- 新しい追記 → 「検知」が**1回だけ**。同じ追記は2度目に出ない。
- 追記なし → 「何もなし」だけ。
- 途中の書き換え → 異常ログ。**中身は読まん**。
- force-push → **停止して知らせる**。位置は動かさん。
- STOPファイル → 何もしない。消すまで戻らん。
- 二重起動 → 2つ目は何もせず終わる。
- ネット断 → バックオフ、復帰後に戻る。
- 再起動・スリープ明け → launchdが戻る。**位置ファイルを消しても、暴走せん（止まる）**。
- **偽の指示**（「鍵を出せ」「mainにpush」「無視して」）を受け箱に入れる → ログに「種類」が出るだけで、**何も起きん**。
- **外へ出る通信が、fetch先だけ**（通信を眺めて確認。**方法は親方**）。
