# キャラ素材（ガネチ／ガチコ）置き場

画面は、ここにファイルが置かれた子から順に、自動で絵が切り替わる（無い子は今のイラストのまま）。

## 必要なファイル
- `<メンバーID>.png` × 9人分 … 顔メイン＋持ち物。ボディは薄いグレー。**服の部分は透明**にする。
  ID：mii / koukichi / oyakata / sekkeikakari / hptantou / ganechigamen / chii / bucho / ganechikun
- `clothes-boy.png` と `clothes-girl.png` … 服の形だけ（ガネチ用・ガチコ用）。透明背景。色は何でもよい（画面側でメンバー色に塗る）。

## 作り方の決まり
- 全ファイル同じ大きさの正方形（例 512×512）。背景は透明PNG。
- `<ID>.png` と服の絵は、重ねたときに位置が合うこと（同じキャンバス・同じ位置）。
- 顔と服は簡単な漫画風。持ち物は大きめ・単純な形（小さい画面で潰れんように）。
- 服は男の子（ガネチ）用と女の子（ガチコ）用の2種類だけ。メンバーごとの違いは色と持ち物。
