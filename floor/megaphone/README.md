# 拡声器（全員への一斉連絡）

## ファイル
- `floor/megaphone/current.json` … 今の連絡1件。書くのは すぎちゃん／みー（みーが置く）。新しい連絡は上書き。
- `floor/megaphone/replies/<メンバーID>.json` … 各自の返事。書いていいのは自分のファイルだけ（状態ファイルと同じルール）。

## 書式
current.json
```json
{ "id": "20261121-0900", "from": "chairman", "from_name": "すぎちゃん", "text": "全員への連絡文", "sent": "2026-11-21T09:00:00+09:00" }
```
`from` は `chairman` か メンバーID（例 `mii`）。送り主本人は返事の対象外。

replies/<ID>.json
```json
{ "id": "koukichi", "msg_id": "20261121-0900", "text": "了解。〇〇します", "updated": "2026-11-21T09:05:00+09:00" }
```
`msg_id` が current.json の `id` と同じ返事だけが「返事済み」になる。違う（前回の）返事は未返信扱い。

## 画面
- フロア画面の「拡声器」マス：連絡文／返事 n/N／各自の返事（未返信は赤で目立つ）。
- 書く欄は、入力して「コピー」でファイルの中身ができる。共有保存はできないので、みーが current.json に置く。
