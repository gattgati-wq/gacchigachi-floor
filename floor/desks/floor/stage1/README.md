作成：まな／監査のチェック表（`../STAGE1-CHECK.md`）に沿った下書き／**v2**（監査のレビューの直し1〜7を反映）／**AIは起こさん**（`claude` を呼ぶ行は無い）
このフォルダの2つは**下書き**（`watch.sh.draft`・`watch.plist.draft`）。**リポジトリの外**に、親方が**手で**置く。

## 入れ方（親方・案）
1. **専用フォルダ**を作る（リポジトリの外。例：`<専用ユーザー>/floor-watch`）。以下 `BASE` と呼ぶ。
2. `watch.sh.draft` を `BASE/watch.sh` にコピーし、**`__BASE__` を `BASE` の絶対パスに直す**。`chmod +x`。
3. `watch.plist.draft` の `__BASE__` も直し、`~/Library/LaunchAgents/com.gacchigachi.floor-watch.plist` に置く（**まだ有効にしない**）。
4. **作り話のリポ**で試験（下）。**全部通ってから**、本物のリポ（スクリプトの `REPO_URL`）で `watch.sh --init` を**人が1回**実行 → `launchctl` で有効化。
5. **止め方**：`BASE/STOP` を作る（あれば何もせず終わる。**人が消すまで戻らん**。再起動後も）。

## 動き（監査のチェック表との対応）
- **fetchだけ**（作業ツリーの無い、ミラー用の bare リポ `BASE/mirror.git`）。**fetch先はスクリプトに固定**。**鍵なし**（公開リポ）。
- **前回の位置**＝`BASE/last_sha`。**無ければ止まる**（人が `--init`）。**祖先でなくなったら（force-push等）止まる**。位置は自動で直さん。
- **見る場所は1つだけ**（`WATCH_PATH`）。**追記だけ**を判定（古いファイルが、新しいファイルの先頭とぴったり一致）。**途中の書き換え・削除は「異常」**。
- **ログは、sha・パス・行数・バイト数・時刻だけ**。**本文は、変数・引数・ログに入れん**。
- **STOP／二重起動のロック（mkdir式）／バックオフ（失敗が続くと最大1時間まで間隔を空ける）／fetchの時間上限（perlのalarm）／ログの上限（1MBで回す・3世代）**。

## v2で直した所（監査のレビュー 2026-11-26）
1. **PATH固定**（`/usr/bin:/bin:/usr/sbin:/sbin`）。launchdのPATHは最小。`/usr/bin/git` は Command Line Tools が要るはず（**親方に確認**）。
2. **追記判定**：`cmp -n` をやめ、`head -c` で比べる／**古い版の末尾が改行**かを確認（無ければ「異常」＝既存の最後の行への書き足しを通さん）／サイズは `git cat-file -s`（本文を読まん）。**見る場所が普通のファイル（100644）か**、**大きすぎ（1MB超）でないか**も見る。
3. **初回（`--init`）のfetchだけ、時間上限を600秒**に。
4. **古いロック（15分超）は回収**して、ログに1行。新しいロック（生きてる持ち主）は奪わん。
5. **環境の遮断**：`GIT_TERMINAL_PROMPT=0 GIT_CONFIG_NOSYSTEM=1 GIT_CONFIG_GLOBAL=/dev/null`＋`credential.helper=`（`GIT_CONFIG_GLOBAL` は git 2.32以上。古いgitでは効かんだけ）。
6. **手で `--init` した時だけ、止まった理由を画面に出す**（STOP・ロック・失敗）。
7. launchd：下の「親方に決めてもらうこと」。
- あわせて：**位置ファイルは原子的に書く**（一時ファイル→mv）＋**40桁の検証**／**STOPの中身に理由（固定語だけ：位置なし・位置が変・祖先でない・ブランチなし）**／**ログの回転は、ロックを取った後**。

## 復旧の手順（止まった時）

2. **STOPを消す**。
3. **`watch.sh --init`**（人が1回。位置を今のmainに合わせる）。**先にSTOPを消さんと、`--init` は何もせん**。
