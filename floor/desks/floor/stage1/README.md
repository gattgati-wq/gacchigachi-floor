作成：まな／監査のチェック表（`../STAGE1-CHECK.md`）に沿った下書き／**AIは起こさん**（`claude` を呼ぶ行は無い）
このフォルダの2つは**下書き**（`watch.sh.draft`・`watch.plist.draft`）。**リポジトリの外**に、親方が**手で**置く。

## 入れ方（親方・案）
1. **専用フォルダ**を作る（リポジトリの外。例：`<専用ユーザー>/floor-watch`）。以下 `BASE` と呼ぶ。
2. `watch.sh.draft` を `BASE/watch.sh` にコピーし、**`__BASE__` を `BASE` の絶対パスに直す**。`chmod +x`。
3. `watch.plist.draft` の `__BASE__` も直し、`~/Library/LaunchAgents/com.gacchigachi.floor-watch.plist` に置く（**まだ有効にしない**）。
4. **作り話のリポ**で試験（下）。**全部通ってから**、本物のリポ（スクリプトの `REPO_URL`）で `watch.sh --init` を**人が1回**実行 → `launchctl` で有効化。
5. **止め方**：`BASE/STOP` を作る（あれば何もせず終わる。**人が消すまで戻らん**。再起動後も）。

## 動き（監査のチェック表との対応）
- **fetchだけ**（作業ツリーの無い、ミラー用の bare リポ `BASE/mirror.git`）。**fetch先はスクリプトに固定**。**鍵なし**（公開リポ）。
- **前回の位置**＝`BASE/last_sha`。**無ければ止まる**（人が `--init`）。**祖先でなくなったら（force-push等）止まる**。位置は自動で直さん。
- **見る場所は1つだけ**（`WATCH_PATH`）。**追記だけ**を判定（古いファイルが、新しいファイルの先頭とぴったり一致）。**途中の書き換え・削除は「異常」**。
- **ログは、sha・パス・行数・バイト数・時刻だけ**。**本文は、変数・引数・ログに入れん**。
- **STOP／二重起動のロック（mkdir式）／バックオフ（失敗が続くと最大1時間まで間隔を空ける）／fetchの時間上限（perlのalarm）／ログの上限（1MBで回す・3世代）**。
