# キャラ素材（ガネチ／ガチコ）

`<メンバーID>-<ポーズ>.webp`（9人×5ポーズ＝45枚）。正方形384px・透明背景・全身・メンバー色。
元のPNG（512px）はキキの納品物。画面用に軽く（約1.7MB）して置いている。

| ポーズ | 使う状態 |
|---|---|
| normal | 待機・完了（完了はチェックを重ねる） |
| work | 作業中 |
| panic | 許可待ち・人待ち |
| yawn | 待機が24時間以上続いた子 |
| sleep | 止まってる（作業中・待ち系で6時間以上更新なし）／状態ファイルなし |

割り振り：ガチコ＝みー・ちぃ・フロア設計係・HP担当／ガネチ＝こー吉・親方・ガネチ画面・部長・ガネチくん
親方は炎仕様（メンバー色 #e53935）。

## 素材がまだの子（例：まな）
絵が届くまでは簡易イラスト（丸い頭＋デスク）で表示する。名札・状態・ボードは素材なしでも全部動く。
絵が届いたら：
1. `img/<メンバーID>-<ポーズ>.webp` を5枚（normal／work／panic／yawn／sleep）置く（例：`img/mana-normal.webp`）
2. members.json のその子に `"art": true` を足す
コードの書き換えは要らない。

### まなの素材（キキ作・藍色 #4356A6）
- `mana-normal`（01）／`mana-work`（02）／`mana-yawn`（03）／`mana-sleep`（04）の4枚＋`mana-done`（05 完了ポーズ）。
- 「焦ってる（panic）」は届いていないので、`mana-normal` で代用して表示する（画像が無いポーズは normal に自動で切り替わる）。
- 完了の子は、members.json に `"art_done": true` があれば `<ID>-done.webp` を使う（無ければ normal）。
