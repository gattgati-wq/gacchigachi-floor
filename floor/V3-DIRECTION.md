# フロア v3 方針（すぎちゃん決定 2026-11-21）

## 土台の決定
- フロア画面の土台は Museスペースをやめて、普通のWEBページにする。
- 理由：拡張が使えない環境でも開けるように。どの端末からでもURLで開ける形がよい。
- 置き場所はこのリポジトリ（gacchigachi-floor）を想定。公開方法はフロア設計係の提案でよい。

## 設計の決定（今夜の分、要点のみ）
- 全画面をセクション（マス目）で構成し、ボード／カレンダー／時計／会長室／取引先窓口／メンバー各自をマスに入れる。空白のマスは作らない。
- 状態ボードは画面の1/3、4列横並び（待機中／作業中／承認待ち／完了）、短文カード全面色付き、黒の太線、ホワイトボード風。高さは最小限。
- カードでも人物でもタップで同じ詳細ウインドウ（状態・タスク・ひとこと・何待ちか・最終更新）。承認待ちは「何の許可待ちか」が見える。
- 詳細ウインドウの書き込み・保存は、WEB側でどう実現するか設計係の提案待ち。
- カレンダー（月表示・今日を目立たせる）とアナログ時計（実際に動く）をボードの横に。
- 人物は簡素なフラットイラスト。カード色＝服の色＝マスの色。軽い動きは可。
- 会長室は小さいマス（ドアと名札だけ）。取引先（キキ・えみ）は人アイコン付きの小さいマス。
- みーの裏方（定期ジョブ7件）は、みーの詳細ウインドウの中で見せる。
- 背景は端末設定に依存させず、明るい色に固定。
- メンバーと状態の正は floor/members.json と floor/status/*.json。データ収集・反映はみーが行う。

詳細な経緯と決定の一覧は、設計係のチャットに送った依頼文と追伸（v2の案そのまま）を参照。
