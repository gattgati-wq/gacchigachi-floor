# フロア v3 方針（すぎちゃん決定 2026-11-21）

## 土台の決定
- フロア画面の土台は Museスペースをやめて、普通のWEBページにする。
- 理由：拡張が使えない環境でも開けるように。どの端末からでもURLで開ける形がよい。
- 置き場所はこのリポジトリ（gacchigachi-floor）を想定。公開方法はフロア設計係の提案でよい。

## 設計の決定（今夜の分、要点のみ）
- 全画面をセクション（マス目）で構成し、ボード／日時プレート／会長室／取引先窓口／メンバー各自をマスに入れる。空白のマスは作らない。
- 状態ボードは4列横並び（待機中／作業中／承認待ち／完了）。キキの素材（真鍮×木のフレーム＋カラーマグネットに名前を載せる形）に合わせる（2026-11-22 更新）。高さは最小限。
- カードでも人物でもタップで同じ詳細ウインドウ（状態・タスク・ひとこと・何待ちか・最終更新）。承認待ちは「何の許可待ちか」が見える。
- 詳細ウインドウの書き込み・保存は、WEB側でどう実現するか設計係の提案待ち。
- 日時プレート1つ（日付と時刻。時刻は毎秒更新）をボードの横に。月表示のカレンダーとアナログ時計は置かない（すぎちゃん決定 2026-11-22：場所を取るため一本化）。
- 人物はキキのキャラ素材（ガネチ／ガチコ）。色＝メンバー色。軽い動きは可。
- 会長室は小さいマス（ドアと名札だけ）。取引先（キキ・えみ）は人アイコン付きの小さいマス。
- みーの裏方（定期ジョブ7件）は、みーの詳細ウインドウの中で見せる。
- 背景は端末設定に依存させず、明るい色に固定。デザインはキキの昼（明るい）版で確定、夜版は作らない（2026-11-22）。
- メンバーと状態の正は floor/members.json と floor/status/*.json。データ収集・反映はみーが行う。

詳細な経緯と決定の一覧は、設計係のチャットに送った依頼文と追伸（v2の案そのまま）を参照。

## 追記（2026-11-22 すぎちゃん決定）
- 見た目は全部、キキの新しい素材に変わる。中身は追加・削除があるが、機能は同じ。
- 拡声器の区画：素材の縦横比に縛られず、都合に合わせて調整してよい。
- 新機能「完成品置き場」：置くのは完成品の**名前のみ**（日付もリンクも無し）。
- リポジトリと画面は公開。お客さんの情報・見せたくない物は載せない。
