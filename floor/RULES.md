# 状態ファイルの書き方ルール（v0.2）

## 基本
- 社員1人につき1枚：`floor/status/<自分のID>.json`
- 書いていいのは自分のファイルだけ
- 書くのは「今の状態」だけ。履歴はGitの記録に任せる（上書きでOK）
- 書く内容は、本当にやったこと・本当の状態だけ。推測や演出は書かない

## 書くタイミング（この3回だけ）
1. 作業を始めた時
2. 待ちになった時（許可待ち・他の社員待ち）
3. 終わった時（idle や done へ書き直すのが「終わり」の1回にあたる）

## コミットの仕方
- 状態ファイル（`floor/status/*.json`）は main への直接コミットでよい
- PRにするのは、ルール変更など大事なものだけ

## 書式（JSON）
```json
{
  "id": "koukichi",
  "name": "こー吉",
  "status": "working",
  "task": "会長ダミーデータ作成",
  "say": "ダミーデータの項目を決めてる",
  "waiting_for": "",
  "updated": "2026-11-20T15:30:00+09:00"
}
```

## 項目の意味
| 項目 | 意味 |
|---|---|
| id | 社員ID（英小文字。members.json と一致させる） |
| name | 表示名（タイトル＝名前） |
| status | 下の6種類から1つ |
| task | 今のタスク名（短く）。タスクがない時は空文字 `""` |
| say | 今やってることの一言。30字まで。フロアの吹き出しにそのまま出る |
| waiting_for | 待っている相手のID。待ちでなければ空 |
| updated | 書いた時刻（日本時間、+09:00付き） |

### usage（任意・自己申告）
自分のセッションの使用量を、**自分の状態ファイルの中に**書く。書けない子（チャット側など）は書かなくてよい（画面には「未計測」と出る）。
```json
"usage": {
  "context_used": 331540,
  "context_max": 1000000,
  "output_tokens": 132617,
  "cost_usd": 5.71,
  "measured": "2026-11-21T12:40:00+09:00"
}
```
| 項目 | 意味 | 取り方（Claude Code のセッション） |
|---|---|---|
| context_used / context_max | 容量（コンテキストの使用量／上限）。画面の容量バーになる | `get_session`（session_id は省略＝自分）の `external_metadata.context_usage` の `used_tokens` / `max_tokens` |
| output_tokens | 累計の出力トークン | 同 `external_metadata.usage.output_tokens` |
| cost_usd | 累計の概算コスト（公開単価での概算） | 同 `external_metadata.usage.cost_usd` |
| measured | 測った時刻（+09:00付き） | 測った時刻 |

- 値は**取った数字をそのまま**書く。推測・概算の作り足しは書かない（分からなければ usage ごと書かない）。
- 状態ファイルを書き直す時（作業開始・待ち・終わり）に、一緒に取り直して書く。測った時刻が古いと、画面ではバーが灰色になる。
- 「今回の仕事だけ」の量は測れない（取れるのはセッション全体の累計）。

### status の6種類
| 値 | 意味 |
|---|---|
| working | 作業中 |
| wait_light | 軽い許可待ち（みー） |
| wait_heavy | 重い許可待ち（会長） |
| wait_member | 他の社員待ち（waiting_for に相手のID） |
| idle | 待機 |
| done | 完了 |

## 許可の記録（みー専用）`floor/approvals/log.json`
- 許可1件につき1件追加：いつ・誰の・どのタスク・軽/重・許可者（みー代行 or 会長）
- みー以外は書かない
- 重い許可は、会長の許可をみーが記録する形

## 禁止
- お客さんの情報（名前・連絡先・予約内容など一切）
- 他の社員のファイルへの書き込み
- パスワード・鍵・トークン（usage の「トークン」は使用量の数字で、認証トークンではない）
- 推測で書くこと（分からない時は idle にして say に「確認待ち」）

## 実験中の約束
- データは会長本人の名前・ダミーだけ
