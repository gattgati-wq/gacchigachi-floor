# 個別連絡（その子だけに話しかける）

拡声器（全員宛て）の個別版。

## ファイル
- `floor/messages/<メンバーID>.json` … その子宛ての連絡1件。すぎちゃん／みーが書き、みーが置く。新しい連絡は上書き。
- `floor/messages/replies/<メンバーID>.json` … 本人の返事。書いていいのは自分のファイルだけ（状態ファイルと同じルール）。

## 書式
messages/<ID>.json
```json
{ "id": "20261121-1500-koukichi", "to": "koukichi", "from": "chairman", "from_name": "すぎちゃん", "text": "連絡や質問の文章", "sent": "2026-11-21T15:00:00+09:00" }
```
`to` はファイル名のIDと同じにする（違うものは無視される）。`from` は `chairman` か メンバーID。

replies/<ID>.json
```json
{ "id": "koukichi", "msg_id": "20261121-1500-koukichi", "text": "返事の文章", "updated": "2026-11-21T15:10:00+09:00" }
```
`msg_id` が連絡の `id` と同じ返事だけが「返事済み」になる。違う（前回の）返事は未返信扱い。

## 画面
- デスクに赤い ✉ ＝連絡あり・未返信（返事が付くと消える）。
- デスクを押した吹き出しと、詳細ウインドウに、連絡と返事が並んで出る。未返信は経過時間つき。
- 詳細ウインドウの「この子に連絡を書く」で、送る人を選んで書き、「コピー（みーに渡す用）」を押すと、上の `messages/<ID>.json` の中身ができる。画面からは直接送れないので、みーが置く。
